for command prompt ===========================================================

1. install keycloak 
2. go to bin directory and open in cmd 
3. D:\keycloak-26.2.4\keycloak-26.2.4\bin>kc.bat start-dev
4. your keycloak now should start (if you use localhost:8080 then you can see something like Create a temporary administrative user)
5. if you earlier logged in earlier already and again you want to start from freshly then you have to do something in cmd like 
6.
		D:\keycloak-26.2.4\keycloak-26.2.4\bin>cd ..
		D:\keycloak-26.2.4\keycloak-26.2.4>rmdir /s /q data & rmdir /s /q conf
7. after this you can see that your all earlier cache from keycloak have been removed and now you can see after refresh or restart of keycloak this same page  like (Create a temporary administrative user) to start from freshly
